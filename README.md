# 🏆 DonateMe – Blockchain Crowdfunding  

**DonateMe** is a decentralized crowdfunding platform that leverages blockchain technology for secure and transparent fundraising.  

<img width="1511" alt="image" src="https://github.com/user-attachments/assets/0d6f531d-a386-47cd-a0d1-d6476f53093f" />

## 🚀 Features  
- **Smart Contract-Based Donations** – Ensuring trust and security.  
- **MetaMask Integration** – Seamless Ethereum transactions.  
- **Decentralized & Transparent** – Immutable records on the blockchain.  
- **User-Friendly UI** – Built with **ReactJS** & **Tailwind CSS**.  

## 🛠️ Tech Stack  
- **Frontend:** ReactJS, Tailwind CSS  
- **Blockchain:** Solidity, Hardhat, Thirdweb  

## 🚀 Getting Started  

### Clone the Repository  
```sh
git clone https://github.com/your-username/DonateMe.git  
cd DonateMe

#Install Dependencies
npm install

```
## Download & Setup MetaMask
1. Install the MetaMask browser extension.
2. Create or import a wallet.
3. Switch to the Sepolia Testnet for testing.
4. Connect your wallet to DonateMe.

## 🏗️ Connect Wallet
- Click on the **Connect Wallet** button.
- Approve the connection in MetaMask.

You’re now ready to donate or create a campaign!

## Run Locally
```sh
cd frontend
npm run dev
```
